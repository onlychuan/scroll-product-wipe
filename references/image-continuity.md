# 给用户的八种图片素材承接提示

请根据下面八种提示，自行准备或生成相邻状态的图片，再交给本技能制作网页。本技能不生成图片。这些提示用于规划相邻图片的内容和关系，按项目需要选择、组合。

| 规则 | 用户定义 | 素材衔接要求 |
| --- | --- | --- |
| 时间承接 | 白天 → 黄昏 → 夜晚 | 保持场景布局与主体锚点，变化集中在时间、环境色与光照。 |
| 镜头承接 | 全景 → 推近 → 产品特写 | 保持观看方向和关注对象，让前后画面的焦点有对应关系。镜头比例变化是有意设计，采用时明确放宽等比例约束。 |
| 物体承接 | 同一个产品保持位置，只改变状态 | 产品中心、视角、比例和共同部位的坐标一致。是原位擦换示例的默认规则。 |
| 动作承接 | 手伸向产品 → 下一屏接着完成动作 | 前一张的动作终点与后一张的起点相接，保持人物、手、产品与动作方向一致。 |
| 光线承接 | 灯光熄灭 → 下一屏由另一束光亮起 | 主体和空间有连续关系，预先安排光源方向与明暗区域，避免边界两侧出现无意的曝光断层。 |
| 空间承接 | 镜头穿过一个门/窗/物体 → 进入下一场景 | 用门框、窗框或物体开口作为共同视觉锚点，连续组织开口内外的视线与空间。 |
| 形态承接 | 完整产品 → 爆炸图 → 内部结构 | 沿用同一产品设计、零件数量和材质，给保留部件设置稳定锚点，提前为展开范围预留画布。 |
| 信息承接 | 上一屏提出问题 → 下一屏马上给答案 | 前后信息一一对应；有文案需求时用独立文本层表达。无文案需求时用图片内容呈现问题与答案，不把字烘焙进素材。 |

## 每组素材的制作约定

先确定：状态顺序、采用的承接规则、画布尺寸、产品锚点、画面占比、视角、背景方式，以及允许变化的内容。

原位产品拆解默认固定相机、画布和产品坐标。物体承接和形态承接可以一起使用；镜头承接与固定比例发生冲突时，按用户实际选择执行，不同时强制两套约束。

用户自行生成下一张时，建议以上一张及原始产品参考为依据，明确“只改变指定状态，其余保持一致”。收到素材后检查真实轮廓，不能只依据提示词宣称已经对齐。若错位明显，向用户指出需重新准备的图片及偏差；不能通过滚动中临时漂移掩盖错位。

## 本项目可复用的状态例子

完整外观 → 去掉面板 → 露出内部组件 → 电路板显露。

这里采用物体承接和形态承接。保持无可见文案。完整爆炸图是否添加由用户选择；状态数量不固定为四张或五张。背景可以逐屏更换颜色，背景边界与产品切换边界重合。
